#Product Data Analysis

The product Data set consists of Product ID,Product Name,Brand Name,Price,Quantity and category.The main purpose of this Assignment is to Analyze product prices,Perform Calculations(SUM,AVG,COUNT etc.),Categorize them(High,Standard),Extract text details(DAY,Month,Conty Code).This assignment consists of Excel Sheet with completed calculations and a PDF document including the Screenshots.
